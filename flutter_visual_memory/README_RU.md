## 📖 О проекте

Это игра для тренировки визуальной рабочей памяти, портированная с Python/Pygame на Dart/Flutter. Игра использует систему динамической регулировки сложности (DDA), которая автоматически адаптирует уровень сложности на основе результатов игрока.

### Основные возможности:

- ✅ Полностью портированная логика игры из Python на Dart
- ✅ Адаптивный интерфейс для разных размеров экранов
- ✅ Динамическая регулировка сложности (DDA)
- ✅ Сохранение результатов игры в CSV формате
- ✅ Система обучающих раундов
- ✅ Статистика и анализ результатов

## 🎮 Как играть

### Процесс игры:

1. **Экран приветствия**
   - Нажмите кнопку "Next" для продолжения

2. **Регистрация**
   - Заполните информацию о себе:
     - Имя (name)
     - Фамилия (last_name)
     - Телефон (mobile)
     - Номер субъекта (sbjct_nmbr)
     - Возраст (age)
     - Пол (gender)
     - Номер глаза (eye_numbr)
     - Астигматизм (astigmatism)
   - Нажмите "Next"

3. **Инструкция**
   - Прочитайте правила игры
   - Нажмите "Next" для обучения

4. **Обучающие раунды** (3 раунда)
   - Раунд 1: 3 цели
   - Раунд 2: 5 целей
   - Раунд 3: 7 целей
   - Практикуйтесь перед основной игрой

5. **Основная игра** (15 раундов по умолчанию)
   - Каждый раунд состоит из:
     - **Фаза запоминания (2 секунды):**
       - Смотрите на сетку 6×6 шестиугольников
       - ЖЕЛТЫЕ шестиугольники = цели для запоминания
       - БЕЛЫЕ шестиугольники = пустые ячейки

     - **Фаза воспоминания:**
       - Все шестиугольники становятся белыми
       - Кликните на те позиции, где были желтые
       - ЗЕЛЁНЫЙ = правильный клик ✓
       - КРАСНЫЙ = неправильный клик ✗

     - **Оценка результата:**
       - Счет = правильные клики / общее количество целей
       - Счет 1.0 = победа!
       - Другой счет = проигрыш

6. **Динамическая регулировка сложности:**
   - Счет > 0.9: сложность увеличивается (+1 цель)
   - Счет < 0.7: сложность уменьшается (-1 цель)
   - Минимум 4 цели, максимум 14 целей

7. **Результаты**
   - После 15 раундов показываются результаты:
     - Всего раундов
     - Средний счет
     - Лучший счет
     - Худший счет

## 🔄 Особенности портирования

### Соответствие Python ↔ Dart:

| Python (Pygame) | Dart (Flutter) | Описание |
|----------------|----------------|----------|
| `buttons.py` | `widgets/custom_*.dart` | UI компоненты |
| `hexagon.py` | `models/hexagon_tile.dart` | Модель шестиугольника |
| `task.py` | `game/task.dart` | Логика задачи |
| `task_guiding.py` | `game/task_guiding.dart` | Обучение |
| `main_game.py` | `game/game_provider.dart` | Основная игра с DDA |
| `welcome_page.py` | `screens/welcome_page.dart` | Приветствие |
| `sign_up_page.py` | `screens/sign_up_page.dart` | Регистрация |
| `guid_page.py` | `screens/guide_page.dart` | Инструкция |
| `start_actual_task_page.py` | `screens/start_actual_task_page.dart` | Начало игры |

### Основные изменения:

1. **Отрисовка:**
   - Pygame Surface → Flutter CustomPainter
   - Pygame события → Flutter GestureDetector

2. **Навигация:**
   - Pygame циклы while → Flutter Navigator
   - Прямое управление экраном → Стек навигации

3. **Асинхронность:**
   - Python time.sleep() → Flutter Future/Timer
   - Синхронные операции → Асинхронные методы

4. **Сохранение данных:**
   - Pandas DataFrame → Dart CSV
   - Прямое сохранение → path_provider для получения директории

## 💾 Сохранение данных

### Формат данных

Игра автоматически сохраняет результаты в CSV файл со следующими данными:

- **Информация о пользователе:** имя, фамилия, возраст и т.д.
- **Данные задачи:** индексы целей, сложность, количество целей
- **Время:** начало/конец запоминания, начало/конец ответа
- **Результаты:** правильные/неправильные клики, счет, победа/поражение
- **Последовательность действий:** порядок кликов, время реакции

### Где хранятся данные:

- **Android:** `/storage/emulated/0/Android/data/com.example.visual_memory_game/files/`
- **iOS:** `Documents` директория приложения
- **Windows:** `%USERPROFILE%\Documents\`
- **macOS:** `~/Documents/`
- **Linux:** `~/Documents/`

### Формат файла:

```
game_data_2025-01-15T14-30-00.csv
```

```dart

```

### Настройка DDA (регулировки сложности):

В файле `game/game_provider.dart`:

```dart
// Увеличение сложности
if (score > 0.9 && score <= 1.0) {
  nTarget++;
}

// Уменьшение сложности
else if (score >= 0 && score < 0.7) {
  nTarget--;
}

// Диапазон целей
nTarget = nTarget.clamp(4, 14);  // Минимум 4, максимум 14
```

## ❓ Часто задаваемые вопросы (FAQ)

### В: Можно ли изменить цвета в игре?

О: Да, цвета можно изменить в файле `models/hexagon_tile.dart`:

```dart
clrHex = isTargetCell
  ? const Color(0xFFFFD700)  // Золотой (желтый) для целей
  : Colors.white;            // Белый для остальных
```

### В: Как экспортировать результаты для анализа?

О: Игра автоматически сохраняет результаты в CSV формате. Найдите файлы в директории Documents вашего устройства.

### В: Можно ли играть без интернета?

О: Да, игра полностью работает офлайн. Интернет не требуется.

### В: Поддерживается ли планшет?

О: Да, игра адаптируется под любой размер экрана, включая планшеты.
